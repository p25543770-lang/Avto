# 🎬 AI-режиссёр — автономный монтаж видео

Веб-приложение, которое **само** делает из сырого видео готовый ролик:
убирает паузы, распознаёт речь, находит дубли и оговорки, ставит главы,
выбирает яркие фрагменты для Shorts и собирает всё в **16:9** и **9:16**.

Всё считается **локально**: ffmpeg + faster-whisper (CUDA) + локальный
OpenAI-совместимый LLM. Интернет не нужен, видео никуда не отправляется.

```
┌────────────┐   ┌──────────────┐   ┌───────────┐   ┌──────────────────┐
│  ИСХОДНИК   │──▶│ удаление     │──▶│ whisper   │──▶│  локальный LLM   │
│  .mp4/.mov │   │ пауз         │   │ + таймкоды│   │  дубли/главы/    │
└────────────┘   │ auto-editor  │   └───────────┘   │  выбор шортсов    │
                 └──────────────┘                   └────────┬─────────┘
                                                             ▼
                                   ┌─────────────────────────────────────┐
                                   │  ffmpeg: нарезка → склейка →        │
                                   │  loudnorm → NVENC → 16:9 и 9:16     │
                                   └─────────────────────────────────────┘
```

---

## ✨ Возможности

| Возможность | Как реализовано |
|---|---|
| Удаление тишины и пауз | `auto-editor` (`--margin 0.2sec`), запасной путь — `ffmpeg silencedetect` |
| Распознавание речи | `faster-whisper`, `word_timestamps=True`, `device=cuda`, `compute_type=int8_float16` |
| Поиск дублей и оговорок | локальный LLM возвращает `keep_segments`; без LLM — эвристика по сходству текста |
| Главы ролика | `chapters` от LLM → `output/<имя>_chapters.txt` |
| Чистовик 16:9 | 1920×1080, кроп/масштабирование по центру, blur-фон для вертикальных исходников |
| Чистовик 9:16 | 1080×1920, `crop=ih*9/16:ih` по центру |
| Шортсы 30–55 с | LLM выбирает 1–5 законченных ярких фрагментов, каждый рендерится в 9:16 **и/или** 16:9 |
| Нормализация звука | `loudnorm=I=-14:TP=-1.5:LRA=11` |
| Аппаратный рендер | `h264_nvenc -preset p4 -cq 20` + `aac 192k` (авто-откат на `libx264`) |
| Слежение за папкой | любой файл, попавший в `input/`, монтируется автоматически |
| Экономия VRAM | модель whisper выгружается сразу после транскрибации, рендер никогда не идёт параллельно |

---

## 🖥 Требования

* Windows 10/11 (проверено на i5-12400F + RTX 2060 SUPER 8 ГБ)
* Python 3.10–3.12
* [FFmpeg](https://www.gyan.dev/ffmpeg/builds/) — в PATH (нужны `ffmpeg` и `ffprobe`)
* NVIDIA-драйвер (для CUDA и NVENC)
* Опционально: локальный LLM — [LM Studio](https://lmstudio.ai/) или [Ollama](https://ollama.com/)

> 8 ГБ VRAM — это ограничение. Приложение специально не грузит LLM в VRAM
> и выгружает whisper сразу после распознавания, поэтому на этой карточке
> всё работает стабильно.

## 🚀 Установка (Windows)

```bat
git clone <репозиторий> Avto
cd Avto

python -m venv .venv
.venv\Scripts\activate

pip install --upgrade pip
pip install -r requirements.txt
```

Либо одной командой — `run.bat` создаёт окружение, ставит зависимости и
запускает приложение с открытым браузером.

### Проверка окружения

```bat
ffmpeg -version            :: должен быть в PATH
nvidia-smi                 :: видеокарта и драйвер
python -c "import torch; print(torch.cuda.is_available())"
```

Если `torch.cuda.is_available()` — `False`, поставьте CUDA-сборку PyTorch:

```bat
pip install torch --index-url https://download.pytorch.org/whl/cu121
```

### Локальный LLM (для поиска дублей и выбора шортсов)

1. Установите **LM Studio**, скачайте модель (например `Qwen2.5-7B-Instruct`
   в формате GGUF, квантизация Q4_K_M).
2. Запустите локальный сервер на порту **1234** (LM Studio → Developer → Start Server).
3. В приложении оставьте адрес `http://127.0.0.1:1234/v1`.

Для **Ollama** подойдёт адрес `http://127.0.0.1:11434/v1` и модель
`qwen2.5:7b-instruct`.

> Без LLM приложение тоже работает: дубли ищутся эвристикой по сходству
> текста, шортсы выбираются по плотности речи. В журнале будет пометка
> «LLM недоступен — работаю в эвристическом режиме».

## ▶️ Запуск

```bat
python run.py --open
```

* адрес: <http://127.0.0.1:8000>
* порт и хост меняются флагами: `python run.py --host 0.0.0.0 --port 9000`

### Что делать в интерфейсе

1. Перетащите видео в зону загрузки (или нажмите «Смонтировать видео»).
2. Выберите форматы: чистовик `16:9` / `9:16`, шортсы `9:16` / `16:9`.
3. При желании задайте адрес LLM, число шортсов и длину шортсов.
4. Следите за прогрессом: 6 шагов, живой журнал, превью результатов.
5. Готовые файлы — в папке `output/`, их можно скачать прямо из браузера.

### Слежение за папкой

Включите переключатель «Следить за папкой `input/`» — любой новый ролик
(`mp4`, `mov`, `mkv`, `avi`, `webm`) будет смонтирован автоматически.

## 📁 Рабочие папки

Создаются автоматически рядом с `run.py`:

```
input/    ← сюда кладут исходники (и сюда попадают загруженные файлы)
temp/     ← промежуточные файлы (чистый ролик, аудио, транскрипт, план монтажа)
output/   ← готовые ролики, шортсы, главы, транскрипт
data/     ← настройки, сохранённые из интерфейса
```

Имена результатов:

```
output/<имя>_final.mp4          чистовик (один формат)
output/<имя>_final_16x9.mp4     чистовик, оба формата
output/<имя>_final_9x16.mp4
output/<имя>_short_1.mp4        шортс
output/<имя>_short_1_9x16.mp4
output/<имя>_short_1_16x9.mp4
output/<имя>_chapters.txt       таймкоды глав
output/<имя>_transcript.txt     расшифровка с таймкодами
```

## ⚙️ Настройки

Меняются в интерфейсе (раздел «Локальный LLM») или через переменные окружения
с префиксом `AVTO_`:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `AVTO_LLM_BASE_URL` | `http://127.0.0.1:1234/v1` | адрес локального LLM |
| `AVTO_LLM_MODEL` | `local-model` | имя модели |
| `AVTO_LLM_API_KEY` | — | ключ, если сервер его требует |
| `AVTO_WHISPER_MODEL` | `medium` | модель распознавания (`large-v3-turbo` ~1.2 ГБ VRAM) |
| `AVTO_WHISPER_DEVICE` | `auto` | `cuda` / `cpu` |
| `AVTO_WHISPER_COMPUTE_TYPE` | `auto` | `int8_float16` для CUDA, `int8` для CPU |
| `AVTO_VIDEO_ENCODER` | `auto` | `h264_nvenc` / `libx264` |
| `AVTO_NVENC_PRESET` | `p4` | пресет NVENC |
| `AVTO_NVENC_CQ` | `20` | качество NVENC |
| `AVTO_AUDIO_BITRATE` | `192k` | битрейт звука |
| `AVTO_SILENCE_MARGIN` | `0.2` | отступ пауз, сек |
| `AVTO_LOUDNORM_I` | `-14` | целевая громкость |
| `AVTO_TRANSCRIBE_BACKEND` | `auto` | `stub` — диагностика без нейросети |
| `AVTO_FFMPEG` / `AVTO_FFPROBE` | — | явные пути к ffmpeg/ffprobe |

## 🧠 Алгоритм монтажа

1. **Удаление тишины** — `auto-editor --margin 0.2sec` → `temp/clean.mp4`.
   Если auto-editor недоступен, используется `ffmpeg silencedetect` + склейка.
2. **Транскрибация** — аудио 16 кГц моно → `faster-whisper` (`language=ru`,
   `word_timestamps=True`) → `temp/transcript.json`. Сразу после этого модель
   удаляется из памяти (`del model; gc.collect(); torch.cuda.empty_cache()`).
3. **Смысловая редактура** — транскрипт (с таймкодами) уходит в локальный LLM.
   Задача: найти оговорки и повторы, удалить ранние неудачные дубли, оставить
   финальный вариант, расставить главы и выбрать 3–5 ярких фрагментов.
   Ожидается строгий JSON:
   `{"keep_segments": [{"start": 0.0, "end": 12.5}], "chapters": [...], "moments": [...]}`.
   Длинные ролики режутся на фрагменты по 10 минут, ответы склеиваются.
4. **Склейка и нормализация** — `ffmpeg` вырезает `temp/clean.mp4` строго по
   `keep_segments` (один проход с фильтром `concat`, поэтому звук не
   рассинхронизируется), применяется `loudnorm=I=-14:TP=-1.5:LRA=11`,
   кодирование `h264_nvenc -preset p4 -cq 20` + `aac 192k`.
5. **Форматы** — `9:16`: `scale=1080:1920` + кроп по центру; `16:9`: 1920×1080,
   для вертикальных исходников — размытый фон с видео по центру.
6. **Шортсы** — выбранные фрагменты (30–55 с) рендерятся отдельно в 9:16 и/или 16:9.

## 🔌 API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/system` | состояние ffmpeg, GPU, whisper, LLM |
| `GET`/`POST` | `/api/settings` | настройки LLM и пайплайна |
| `POST` | `/api/jobs` | загрузка видео + запуск монтажа |
| `GET` | `/api/jobs` | список задач |
| `GET` | `/api/jobs/{id}` | статус и журнал |
| `GET` | `/api/jobs/{id}/events` | live-прогресс (SSE) |
| `GET` | `/api/jobs/{id}/result` | результаты и ссылки на файлы |
| `POST` | `/api/jobs/{id}/cancel` | остановить задачу |
| `GET` | `/api/output` | список готовых файлов |
| `GET` | `/api/files/{name}` | скачать / отдать видео (поддержка Range) |
| `GET`/`POST` | `/api/watch` | слежение за `input/` |

## ❓ Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| «ffmpeg не найден» | не добавлен в PATH, либо укажите `AVTO_FFMPEG=C:\ffmpeg\bin\ffmpeg.exe` |
| «faster-whisper не установлен» | `pip install faster-whisper` (Windows требует VC++ Redistributable) |
| `torch.cuda.is_available() == False` | поставьте CUDA-сборку PyTorch и проверьте драйвер |
| «LLM недоступен» | запустите сервер LM Studio/Ollama и проверьте адрес в настройках |
| Рендер идёт на процессоре | нет драйвера NVIDIA → `h264_nvenc` недоступен, сработал авто-откат на `libx264` |
| Долгая транскрибация | модель `medium` на CPU — переключитесь на `small`/`base` или проверьте CUDA |
